# ISTQB 문서 표기 규칙

## 용어 표기

- 용어는 영어를 기본 표기로 삼고, 복합어의 단어 사이는 언더스코어(`_`)로 연결한다.
- 약어가 있으면 약어를 우선하고, 약어가 없으면 소문자 영어 용어를 사용한다.
- 용어 목록에서는 `영어_용어(한글_표기)` 형식으로 적는다. 예: `state_diagram(상태_다이어그램)`.
- 한글 표기가 여러 단어로 이루어지면 단어 사이를 언더스코어로 연결한다.
- 하이픈(`-`)으로 연결된 영어 복합어는 언더스코어(`_`)로 바꾼다.
- 약어·영문명·한글 표기 중 확인되지 않은 정보는 임의로 만들지 않고 `TBD`로 표시한다. 약어가 실제로 없는 것이 확인되면 약어 칸을 생략한다.
- 같은 영어 표기를 괄호 안에 반복하지 않는다. 중복 정보는 영어 용어 하나만 남긴다.

## 적용 범위

- 문서별로 지정된 용어 목록과 적용 범위를 따른다.
- `ISTQB_CTFL_FL_Syllabus_v.4.0.1_ko.md`에서는 `[terminologies]` 위쪽만 이 용어 표기 규칙의 적용 대상으로 삼는다.
- `[terminologies]` 아래는 별도 요청이 없는 한 수정하지 않는다.
- 문서의 `_______________________________________________________________` 표시는 블록 구분자다. 요청한 블록 밖의 내용은 변경하지 않는다.

## 제목 표기

- 절 번호가 붙은 구분선 제목은 `>>> TODO 절번호 제목` 형식으로 표기한다.
